# Release notes 0.5.1 (Firefox Add-ons, Chrome Web Store, Edge Add-ons)

The same text for all three stores. On Firefox Add-ons paste it into *Upload Version → Release notes*,
one block per language (switch the language at the top of the form).

## English

```
Fixed
- The speed keys (S, D, R, G, Z, X) no longer take letters from pages that read the keyboard themselves — a terminal, a remote desktop, a game or an editor drawn on a canvas. The keys now work only for media in use: a video on screen, or audio / video that plays or has played. They are left to the page while a canvas has the focus, on pages drawn on a large canvas, for live streams (calls, remote screens), and when the only media is a short sound or one that never played.
- The power button now switches off everything for the site, not only the sound processing: the speed and jump keys go back to the page, the video plays at its normal speed, and the tab plays on the default device again. Switching it back on brings the site's speed and output device back.
```

## Русский

```
Исправлено
- Клавиши скорости (S, D, R, G, Z, X) больше не забирают буквы у страниц, которые сами работают с клавиатурой: терминал, удалённый рабочий стол, игра или редактор на канвасе. Теперь клавиши действуют, только когда на странице есть видео на экране либо аудио или видео, которое играет или уже играло. Они остаются у страницы, когда фокус на канвасе, на страницах, нарисованных на большом канвасе, для живых потоков (звонки, удалённый экран) и когда единственный звук на странице — короткий сигнал или ни разу не игравший элемент.
- Кнопка питания теперь выключает для сайта всё, а не только обработку звука: клавиши скорости и перемотки возвращаются странице, видео идёт с обычной скоростью, вкладка снова играет на устройстве по умолчанию. При включении скорость сайта и устройство вывода возвращаются.
```

# Release notes 0.5.0 (addons.mozilla.org)

Changes since 0.2.1, for Firefox only (the Chrome / Edge items of the CHANGELOG are left out).
Paste into *Upload Version → Release notes*, one block per language (switch the language at the top of the form).

## English

```
New
- Output device per tab: "Play on" in the Booster and in every Mixer row sends a tab to other speakers or headphones. The first choice opens Firefox's device picker from a button on the page; later visits switch over with the first click on the page. Remembered per site; back to the default device if the chosen one is missing. Players in a frame of the same site follow along. Not available on Firefox for Android.
- Playback speed 0.1×–16× with a log-scale slider (Firefox plays sound between 0.125× and 8×; the popup says so outside that range).
- Speed keys on pages: S / D slower / faster, R back to 1×, G between 1× and the last speed, Z / X back / forward 10 s. Step, jump and every key can be changed or turned off, also per site. Optional: hold for 2×, A-B loop, frame steps, Shift + wheel over a video.
- A short "1.5×" badge over the video confirms a speed change (with the time left for longer videos), then disappears.
- Keyboard shortcuts for speed faster / slower / 1× (no keys by default — set them in about:addons → ⚙ → Manage Extension Shortcuts).
- Pitch: raise or lower voice and music by up to 12 semitones, independent of the speed.
- Mixer: "Same loudness in all tabs".
- Sound profiles: save all settings of a site under a name and apply them to any site in one click.
- "Only on sites I choose": every other site is left completely untouched.
- Maximum volume: 150 / 200 / 300 / 400 / 600%.
- Optional settings sync through your Firefox account.
- Exact values: click the gain or the speed to type a value; Shift + wheel over the gauge changes the gain by 1%.

Changed
- Mixer sliders set the volume of that tab only — two tabs of the same site can play at different levels.
- Equalizer: one switch per kind (Parametric, 10 bands, 31 bands); a dot shows which one is on. Presets apply to the equalizer that is on.
- Parametric EQ: a × on every band to remove it.
- A paused tab no longer keeps the computer awake (processing sleeps after 10 s without playback).
- Much lower CPU use while the popup or the sidebar is open.
- Clearer notices when a page's audio can't be processed (copy protection or audio from another site).
- Players that reset the speed when a new video starts get the site's speed again.
- The shortcut hint in Settings is now a link to Firefox's shortcut page.

Fixed
- Right after Firefox starts (restored tabs), a page could wait for its settings and speed keys went to the site.
- The limiter's "Reduction" no longer shows about −1 dB when nothing is limited.
```

## Русский

```
Новое
- Устройство вывода для каждой вкладки: «Устройство» в «Бустере» и в каждой строке микшера отправляет вкладку на другие колонки или наушники. Первый выбор открывает окно выбора устройства Firefox с кнопки на странице; при следующих визитах устройство переключается с первого клика по странице. Запоминается для сайта; если устройства нет — звук идёт на устройство по умолчанию. Плееры во фреймах того же сайта переключаются вместе со страницей. Недоступно в Firefox для Android.
- Скорость воспроизведения 0,1×–16× с логарифмическим ползунком (Firefox воспроизводит звук от 0,125× до 8×; вне этого диапазона окно расширения об этом говорит).
- Клавиши скорости на страницах: S / D медленнее / быстрее, R — 1×, G — между 1× и последней скоростью, Z / X — назад / вперёд на 10 с. Шаг, прыжок и каждую клавишу можно изменить или выключить, в том числе для сайта. По желанию: удержание для 2×, повтор A–B, покадровый шаг, Shift + колесо над видео.
- Короткая плашка «1.5×» над видео подтверждает смену скорости (для длинных видео — с оставшимся временем) и исчезает.
- Сочетания клавиш для скорости быстрее / медленнее / 1× (по умолчанию не назначены — about:addons → ⚙ → Управление сочетаниями клавиш).
- Высота тона: поднять или опустить голос и музыку до 12 полутонов, независимо от скорости.
- Микшер: «Одинаковая громкость во всех вкладках».
- Профили звука: сохранить все настройки сайта под именем и применить к любому сайту в один клик.
- «Только на выбранных сайтах»: остальные сайты не затрагиваются вообще.
- Максимальная громкость: 150 / 200 / 300 / 400 / 600%.
- Синхронизация настроек через аккаунт Firefox (по желанию).
- Точные значения: клик по усилению или скорости — ввести число; Shift + колесо над шкалой меняет усиление на 1%.

Изменено
- Ползунки микшера меняют громкость только своей вкладки — две вкладки одного сайта могут звучать по-разному.
- Эквалайзер: свой переключатель у каждого типа (параметрический, 10 полос, 31 полоса); точка показывает, какой включён. Пресеты применяются к включённому эквалайзеру.
- Параметрический эквалайзер: × на каждой полосе для удаления.
- Вкладка на паузе больше не мешает компьютеру уснуть (обработка засыпает через 10 с без воспроизведения).
- Намного меньше нагрузка на процессор, пока открыто окно расширения или боковая панель.
- Понятнее объясняется, почему звук страницы нельзя обработать (защита от копирования или звук с другого сайта).
- Плееры, сбрасывающие скорость при смене видео, снова получают скорость сайта.
- Подсказка о сочетаниях клавиш в настройках теперь ссылка на страницу сочетаний Firefox.

Исправлено
- Сразу после запуска Firefox (восстановленные вкладки) страница могла ждать настройки, и клавиши скорости уходили сайту.
- «Подавление» лимитера больше не показывает около −1 дБ, когда ничего не ограничивается.
```
